# Ticket Support System – Spring Boot 3 REST API

```
A complete backend built with Spring Boot 3 to manage customer support tickets.
This project is developed as part of DeepCoder's YouTube project series for backend developers.
```
# Features
```
Season 1:
- Basic CRUD APIs for Ticket entity
- Enum-based status and priority
- Layered architecture (Controller, Service, Repository)

Season 2:
- DTO-based validation
- Global Exception Handling
- Multi-model setup (Customer, Executive)
- Relationship mapping (M:1)
- Filtering, Searching, Sorting, Cascade Delete

Upcoming (Season 3):
- Authentication & Authorization with JWT
- Refactoring for production readiness
- Integration with React frontend
```

# Tech Stack

```
- Java 21
- Spring Boot 3.x
- Spring Data JPA
- Hibernate Validator
- MySQL / H2
- Maven
- Postman for API testing
```

# Set Up
```
1. Clone the repository
   git clone https://github.com/<yourusername>/ticket-support-system.git

2. Navigate to the project
   cd ticket-support-system

3. Build and run
   mvn spring-boot:run
```
